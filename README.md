## HOW TO ADD MAPPINGS
#### Copy the contents of `version/*.csv` to `conf/*.csv` (merge, not replace), then run `cleanup` and `decompile` (WARNING: those will fully wipe all your changes, backup any changed files before running)

## HOW TO USE `run.bat` SCRIPT
#### `scripts/run.bat` convenience script that compiles and runs the game, run `recompile` `reobfuscate` `startclient`
